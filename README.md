# 🎵 ScreenSound - Persistência de Dados com Entity Framework Core

Este repositório contém o projeto prático desenvolvido durante o curso **.NET: Persistindo dados com Entity Framework Core** da [Alura](https://www.alura.com.br/).

O objetivo principal do projeto é compreender a transição da manipulação de banco de dados nativa (ADO.NET) para o uso de uma ferramenta ORM (Object-Relational Mapping) moderna, dominando a persistência, consultas, relacionamentos e controle de versão do banco de dados.

## 🎯 Conteúdos Estudados & Praticados

- **Acesso NATIVO com ADO.NET:** Conexão com SQL Server e execução de comandos SQL.
- **Padrão DAL (Data Access Layer):** Isolamento da camada de acesso a dados.
- **Entity Framework Core:** Mapeamento de entidades, convenções e refatoração da camada de dados.
- **Generics em C# (`DAL`):** Criação de uma classe DAL genérica e reutilizável para qualquer entidade.
- **EF Core Migrations:** Versionamento do esquema do banco de dados com `Add-Migration` e `Update-Database`.
- **Mapeamento de Relacionamentos:** Configuração de relacionamentos entre tabelas (ex: Artista e Músicas) e carregamento de dados (Lazy Loading/Proxies).

## 🛠️ Tecnologias Utilizadas

- **C# / .NET**
- **Entity Framework Core**
- **SQL Server**
