# 🎵 ScreenSound - Persistência de Dados com Entity Framework Core

Este repositório contém o projeto prático desenvolvido durante o curso **.NET: Persistindo dados com Entity Framework Core** da [Alura](https://www.alura.com.br/).

O objetivo principal do projeto é compreender a transição da manipulação de banco de dados nativa (ADO.NET) para o uso de uma ferramenta ORM (Object-Relational Mapping) moderna, dominando a persistência, consultas, relacionamentos e controle de versão do banco de dados.
